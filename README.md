# ray-tracer-challenge-java
Raytracer implementation following the book "The Ray Tracer Challenge".

Making this public in case the code might be a helpful example for someone.

# Contributing
Policy may change in the future, but for now this repo is not open for pull
requests.

# Generative AI Policy
No Generative AI has been used in the development of anything in this repository.

Issues generated with AI agents will be rejected.

If this repository eventually opens up to external pull requests, any pull requests
generated with AI agents will also be rejected.
